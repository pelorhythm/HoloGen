# HoloGen — SF風ホログラム計器ジェネレーター for After Effects

https://holo.ui8.dev/ のような3Dホログラム計器（リング積層＋読み出しテキスト＋グリッド＋ダスト）を、After Effects内でワンクリック・ランダム生成するScriptUIパネルです。

## インストール

`HoloGen.jsx` を以下にコピーして AE を再起動：

```
/Applications/Adobe After Effects 2026/Scripts/ScriptUI Panels/
```

→ **ウィンドウメニュー → HoloGen.jsx** でパネルが開きます（ドッキング可能）。

※ このMacの AE 2026 にはインストール済み。スクリプトを更新したときは同じ場所に上書きコピーして AE を再起動してください。

## 使い方

### 生成
- **★ ランダム生成** … シードと設定をランダムに振り直して新規コンポを生成（色・要素ON/OFFは維持）
- **この設定で生成** … 下の設定値のまま生成
- **シード** … 同じシード＋同じ設定なら同じ結果を再現。🎲で振り直し

### 設定
- リング数 / 基本サイズ / レイヤー間隔 / 全体速度 / フリッカー / 呼吸 / 全体回転
- **要素**: コールアウト・グリッド・ダストのON/OFF
- **品質**: 軽量（プレビュー重い時）/ 標準 / 高密度
- **カラー**: メイン（線）/ アクセント（バー・ドット）/ テキスト。デフォルトは白

### レイヤー詳細（生成後の個別調整）
1. HOLOコンポを開いた状態で「リスト更新」
2. リストからリングを選択（AE上でも選択されます）
3. 種類（ワイヤー/目盛り/ドット/円弧）・半径・回転速度・不透明度を変えて「このレイヤーに適用」
   - 種類を変えると、そのレイヤーの中身だけ作り直されます（位置・親子・エフェクト値は保持）

### 生成後にAE上で一括調整（HOLO_CTRLレイヤーのエフェクト）
- Main / Accent / Text Color … 各色
- Global Speed … 全アニメーション速度（100=等速）
- Flicker / Breathe / Orbit Spin / Global Scale
- Callout Opacity / Grid Opacity / Dust Opacity

各リングレイヤーにも Radius / Spin / Ring Opacity のスライダーがあり、タイムラインから直接キーフレームも打てます。

## 仕上げの推奨（意図的に入れていないもの）

グローと色収差はAE標準エフェクトで後がけしてください：
1. 調整レイヤーを最上位に追加
2. **グロー**（グロー半径 20〜60 / しきい値 40〜60%あたりから調整）
3. 必要なら **色収差**（レンズ補正やRGB分離系）

## レイヤー構成

生成コンポの上位4レイヤーは固定のリグです：

1. `HOLO_CTRL` … 一括コントロール（2D・非表示）
2. `HOLO_ROOT` … ホログラム全体の親（アンカーはセンター）
3. `HOLO_CAM_ORBIT` … カメラのオービット用ヌル（アンカーはセンター）
4. `HOLO_CAM` … カメラ

その下に2Dのリーダー線（HOLO_TEXTLINE_*）、さらに下に3D要素（テキスト・リング・グリッド・ダスト）が並びます。コールアウトはテキストごと、リングにペアレントされた追跡ヌル（`HOLO_ANCHOR_*`・シャイで非表示）にぶら下がっています。テキストはリングの回転に位置ごと追従し、リーダー線は毎フレーム「テキスト下線 → 取り付き点」を画面座標で結び直すため、**回転してもラインの長さは一定のまま、当初の位置を指し続けます**（テキストの向きだけ常にカメラへ正対）。

パネルは縦幅が足りないとき右端にスクロールバーが出ます。

## 注意・既知の制限

- **`HOLO_CTRL` レイヤー名と各エフェクト名は変更しないでください**（全レイヤーがエクスプレッションで名前参照しています）
- カメラは `HOLO_CAM_ORBIT`（ヌル）の回転でオービットできます。不要なら削除して自分のカメラを使ってOK
- コールアウトのフォントは Menlo。環境に無い場合はAEが代替フォントに置き換えます
- 交点スティックは十字2枚の簡易表現です（AEのシェイプレイヤーは平面のため）
- 再現性は「同じMac・同じAE・同じスクリプトバージョン」の範囲で保証
- 生成はUndoグループ1回分＝ Cmd+Z で丸ごと取り消せます
